# HabitGrid

Sieben feste Gewohnheiten (S F M B D T G) auf einem festen Jahresraster 2026.
Zelle R1 C1 = 05-01-2026, Zelle R7 C51 = 27-12-2026, 51 Spalten mal 7 Reihen.

Eine Seite, kein Server, keine Abhaengigkeiten. Die Haekchen liegen im
Browserspeicher des Geraets. Optional legt die App zusaetzlich eine geheime
Kopie in einem GitHub-Gist ab, dafuer braucht sie einen Token mit dem
Recht `gist`, der nur auf dem Geraet gespeichert wird.
