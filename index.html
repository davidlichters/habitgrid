Die Häkchen liegen auf diesem Gerät. Mit einem GitHub-Schlüssel legt die App zusätzlich eine geheime Kopie in deinem GitHub ab, nach jedem Tippen.

Schlüssel holen: github.com/settings/tokens → nur den Haken gist setzen → erzeugen → hier einsetzen. Der Schlüssel bleibt auf diesem Gerät und geht nur an GitHub.
